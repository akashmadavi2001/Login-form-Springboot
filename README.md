#Login form SpringBoot
Login form with data handle

Login Page – Users are prompted to log in. If they do not have an account, they can register through the Sign Up option.
Sign Up Page – New users create an account by providing the required details.
Home Page – After successful authentication, users are taken to the Home Page, which serves as the main dashboard of the application.
